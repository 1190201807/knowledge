# 线程安全学习笔记

> 目标：从"知道线程安全很重要"到"能在工程里设计、评审、定位并发问题"。

## 使用方式

1. 按 [学习路线](学习路线.md) 的阶段推进，以**能独立完成动手实验**为完成标准，不以"看完资料"为准。
2. 设计和评审时过 [并发十问](并发十问.md)；每学完一个阶段，回来补对应问题的"我的理解"。
3. 工程中随时查 [工程检查清单](工程检查清单.md)。
4. 每踩一个坑，记到 [错题本](错题本.md)。

## 学习地图

| 阶段 | 主题 | 这个阶段结束后你能回答 |
|---|---|---|
| 0–1 | 基础与问题意识 | 线程为什么不安全？怎么稳定复现？ |
| 2 | 同步原语 | 这把锁保护什么？怎么避免死锁？ |
| 3 | 内存模型 | happens-before 是什么？DCL 为什么要 volatile？ |
| 4 | 并发模式与高层抽象 | 该用锁、原子类、消息传递还是不可变对象？ |
| 5 | 诊断与性能 | 线上卡住/数据错乱，怎么定位和量化？ |
| 6 | 无锁与源码进阶 | 工业级并发组件是怎么实现的？ |

## 贯穿全程的三条原则

1. **能不共享就不共享**：不可变、线程封闭、消息传递优先于加锁。
2. **先正确，再性能**：任何优化都要有压测数据支撑。
3. **靠工具，不靠肉眼**：并发 bug 靠 race detector、压测和监控抓，不靠 code review 的灵感。
